# WYVERSE 공식 홈페이지

병의원 사업 파트너 WYVERSE(와이버스)의 소개 사이트입니다.
빌드 도구 없이 `index.html` 한 파일로 동작합니다.

## 구성

```
.
├── index.html   # 사이트 전체 (HTML + CSS + JS 단일 파일)
└── README.md
```

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. (예: `wyverse-site`)
2. `index.html`과 `README.md`를 저장소 **루트**에 올립니다.
3. 저장소 → **Settings** → 왼쪽 메뉴 **Pages**로 이동합니다.
4. **Source**를 `Deploy from a branch`로 두고, Branch를 `main` / `/ (root)`로 지정한 뒤 **Save**를 누릅니다.
5. 1~2분 뒤 `https://<계정명>.github.io/wyverse-site/` 에서 열립니다.

### 도메인 연결

1. 저장소 루트에 `CNAME` 파일을 만들고 도메인만 한 줄 적습니다. (예: `wyverse.co.kr`)
2. 도메인 등록업체 DNS에서 아래를 설정합니다.
   - `www` → CNAME → `<계정명>.github.io`
   - 루트 도메인 → A 레코드 → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. Settings → Pages에서 **Enforce HTTPS**를 켭니다.

## 수정 가이드

- **색상** — `index.html` 상단 `:root`의 `--key: #B75041` 한 곳만 바꾸면 사이트 전체 강조색이 바뀝니다.
- **연락처** — `#contact` 섹션의 전화번호·이메일. `tel:`, `mailto:` 링크도 함께 수정해야 합니다.
- **로드맵 수치** — `#roadmap` 표의 `개시 조건` 열.
- **폰트** — Pretendard를 CDN으로 불러옵니다. 오프라인 환경이 필요하면 폰트 파일을 저장소에 넣고 `@font-face`로 교체하십시오.

## 문의 폼

`#inquiry` 섹션의 폼은 **모든 항목이 형식에 맞아야 전송 버튼이 활성화**됩니다.

| 항목 | 검증 규칙 |
| --- | --- |
| 성함 | 한글 또는 영문 2자 이상 |
| 연락처 | `010-0000-0000` 형식 (숫자 입력 시 하이픈 자동 삽입) |
| 이메일 | `name@example.com` 형태 |
| 진료과목 · 개원 예정 시기 | 목록에서 선택 필수 |
| 희망 지역 | 2자 이상 |
| 문의 내용 | 10자 이상 500자 이하 |
| 개인정보 동의 | 체크 필수 |

- 항목에서 커서가 빠져나간 뒤부터 오류 문구가 표시됩니다. (입력 중에는 잔소리하지 않습니다)
- 화면에 보이지 않는 `회사명` 필드가 채워지면 봇으로 판단해 전송하지 않습니다.

### 전송 방식 설정

`index.html` 하단 스크립트의 `var ENDPOINT = '';` 한 줄로 동작이 갈립니다.

- **비워 두면** — 메일 앱이 열리고 입력 내용이 본문에 자동으로 채워집니다. 별도 가입 없이 바로 동작합니다.
- **주소를 넣으면** — 해당 주소로 전송되고 페이지 이동 없이 완료 문구가 표시됩니다.

[Formspree](https://formspree.io) 기준 설정 순서입니다.

1. 가입 후 새 폼을 만들고 `wyverse.ltd@gmail.com`을 수신 주소로 지정합니다.
2. 발급된 주소(`https://formspree.io/f/xxxxxxxx`)를 복사합니다.
3. `var ENDPOINT = 'https://formspree.io/f/xxxxxxxx';` 로 수정합니다.

무료 요금제는 월 50건까지 수신됩니다.

> 브라우저에서 하는 검증은 개발자 도구로 우회할 수 있습니다. 스팸이 늘면 Formspree의 reCAPTCHA 옵션을 함께 켜십시오.

## 아직 채워야 할 것

- 대표 이미지(OG 이미지) — `og:image` 메타 태그 추가 시 카카오톡·슬랙 공유 시 썸네일이 표시됩니다.
- 사업장 주소 — 확정 후 `#contact`의 OFFICE 항목에 추가.
- 개인정보처리방침 — 문의 폼으로 개인정보를 수집하므로 별도 페이지 마련을 권장합니다. 현재는 폼 안에 수집 항목·목적·보유 기간을 명시해 두었습니다.
